Kit de Recuperação · Aula 05

🎬 Modelo Base StreamVibe (3 Telas)

Não encontrou ou perdeu o seu projeto da Aula 04? Use este kit para colocar as 3 telas editáveis direto no seu Figma em menos de 1 minuto.

1. Copie ou Baixe o Modelo

Clique em "Copiar Todas para o Figma" abaixo (ou baixe o arquivo .svg).

2. Cole no Seu Figma

Crie um Design File em branco no Figma e pressione Ctrl + V (ou arraste o .svg baixado para a tela).

3. Converta em Frames

Desagrupe (Ctrl + Shift + G) e, selecionando cada tela, aperte Ctrl + Alt + G para transformar em Frame (390 × 844).

1. Tela de Login 390 × 844 px
2. Tela de Cadastro 390 × 844 px
3. Home + Carrossel 390 × 844 px (4 Cards)
