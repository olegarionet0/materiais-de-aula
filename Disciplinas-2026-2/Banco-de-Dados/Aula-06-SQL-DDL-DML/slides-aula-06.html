Conteúdo de Apoio para Explicação:

Teoria/Explicação: Lembre aos alunos que o modelo lógico era apenas um projeto (uma planta baixa). O SGBD não lê PDF ou imagem. Ele precisa de comandos de texto precisos para saber o que fazer. O SQL é a linguagem universal dos bancos relacionais.

Dinâmica de Sala: Pergunte: "Vocês acham que o MySQL entende português? Não, ele entende SQL."

🏗️ DDL (Data Definition Language)

  • São os comandos que mexem na ESTRUTURA.
  • Constroem as "prateleiras" onde os dados vão ficar.
  • Principais: CREATE, ALTER, DROP
CREATE DATABASE escola;
USE escola;

CREATE TABLE aluno (
    id_aluno INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    matricula VARCHAR(20) UNIQUE
);

Conteúdo de Apoio para Explicação:

Teoria/Explicação: DDL é a linguagem de definição. Quando você executa um DDL, você não está colocando nenhum "aluno" no sistema, apenas criando a tabela que irá recebê-los. É como construir uma estante vazia. Pontue o uso do USE banco; para selecionar o banco alvo.

Dinâmica de Sala: Chame a atenção para os pontos-e-vírgulas (;) ao final de cada instrução e a vírgula separando as colunas.

🗂️ Tipos de Dados Comuns

  • INT: Números inteiros (1, 100, -5)
  • VARCHAR(n): Texto com limite de caracteres (nome, email)
  • DATE: Data (YYYY-MM-DD)
  • DECIMAL(p, s): Número quebrado (ex: preço, nota)

Conteúdo de Apoio para Explicação:

Teoria/Explicação: O tipo de dado é uma regra de integridade. Se a coluna é INT e você tenta inserir 'João', o SGBD vai dar erro (Isso garante Consistência - ACID). O VARCHAR economiza espaço em disco em relação ao antigo CHAR estático.

✏️ DML (Data Manipulation Language)

  • São os comandos que mexem nos DADOS (linhas).
  • Eles realizam o famoso CRUD!
  • Hoje: INSERT (C) e SELECT (R)
-- Inserindo um registro (CREATE)
INSERT INTO aluno (nome, matricula) 
VALUES ('Maria Santos', '20261005');

-- Consultando registros (READ)
SELECT * FROM aluno;

Conteúdo de Apoio para Explicação:

Teoria/Explicação: DML popula e lê as prateleiras que o DDL criou. Destaque que textos (VARCHAR) e datas no VALUES precisam estar entre aspas simples ('') no SQL, não duplas. O asterisco (*) no SELECT significa "todas as colunas".
