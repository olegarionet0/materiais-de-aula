Da Linha Bruta ao Indicador de Negócio

Na Aula 10, aprendemos a unir dados com INNER JOIN e LEFT JOIN.

No entanto, gestores e sistemas analíticos raramente leem 10.000 linhas soltas. Eles precisam de resumos consolidados:

Perguntas Gerenciais:
  • Quantos produtos há em cada setor?
  • Qual o faturamento total acumulado?
  • Qual o preço médio por categoria?
Solução em Banco de Dados:
  • Funções de Agregação: operam sobre um conjunto de linhas e devolvem 1 único valor.
  • GROUP BY: divide as linhas em grupos antes do cálculo.

As 5 Funções de Agregação Fundamentais

Função O que calcula? Exemplo de Aplicação
COUNT() Contagem de registros / ocorrências SELECT COUNT(*) FROM produtos;
SUM() Somatório aritmético de valores numéricos SELECT SUM(preco) FROM produtos;
AVG() Média aritmética (Average) SELECT AVG(preco) FROM produtos;
MIN() Menor valor presente na coluna SELECT MIN(preco) FROM produtos;
MAX() Maior valor presente na coluna SELECT MAX(preco) FROM produtos;

A Pegadinha do COUNT: Com ou sem NULL?

COUNT(*)

Conta todas as linhas físicas retornadas, inclusive aquelas que contenham valores NULL em algumas colunas.

-- Retorna 7 linhas
SELECT COUNT(*) FROM produtos;
COUNT(coluna)

Conta apenas as ocorrências onde a coluna informada NÃO É NULA (ignora NULL).

-- Se 1 produto não tiver categoria,
-- este SELECT retornará 6!
SELECT COUNT(categoria_id) 
FROM produtos;

Agrupando Dados com GROUP BY

Quando misturamos colunas identificadoras normais com funções agregadas, o SGBD exige a instrução GROUP BY:

SELECT c.nome AS categoria, COUNT(p.id) AS total_produtos
FROM categorias AS c
INNER JOIN produtos AS p ON c.id = p.categoria_id
GROUP BY c.id, c.nome
ORDER BY total_produtos DESC;
Regra de Ouro da Sintaxe SQL:
Toda coluna presente no SELECT que não esteja envelopada por uma função de agregação (como COUNT ou AVG) deve constar no GROUP BY.

O Confronto Decisivo: WHERE vs HAVING

WHERE (Filtro Prévio)
  • Filtra linhas individuais do banco de dados antes da agregação.
  • NUNCA aceita funções de agregação diretamente.
  • Exemplo: "Apenas produtos com preço maior que R$ 50".
HAVING (Filtro do Grupo)
  • Filtra os grupos consolidados após a função de agregação rodar.
  • Trabalha com resultados de COUNT, SUM, AVG.
  • Exemplo: "Apenas categorias com mais de 2 produtos".

HAVING na Prática

Filtrando grupos consolidados:

SELECT c.nome AS categoria, 
       COUNT(p.id) AS total_produtos,
       AVG(p.preco) AS media_preco
FROM categorias AS c
INNER JOIN produtos AS p ON c.id = p.categoria_id
WHERE p.preco > 10.00          -- 1º: filtra os produtos baratos
GROUP BY c.id, c.nome          -- 2º: agrupa por categoria
HAVING COUNT(p.id) >= 2        -- 3º: mantém só categorias com 2+ itens
ORDER BY media_preco DESC;     -- 4º: ordena o resultado

Ordem Mental de Processamento de uma Query

  1. FROM / JOIN: localiza e une as tabelas físicas.
  2. WHERE: filtra linhas brutas individuais.
  3. GROUP BY: consolida os registros em blocos.
  4. HAVING: filtra os blocos/grupos consolidados.
  5. SELECT: projeta as colunas e executa aliases.
  6. ORDER BY / LIMIT: ordena e fatia a exibição.
