Parte 1

Dado, Informação, Fato e Metadados

Construindo os blocos fundamentais dos sistemas de informação.

🔢 O que é um Dado?

  • Elemento em seu estado bruto, cru.
  • Desconectado de qualquer contexto.
  • Sozinho, não possui significado intrínseco ou utilidade imediata.
Exemplos:
• 35 (Pode ser uma idade, uma temperatura, o número de uma casa...)
• "Maria" (Apenas um nome sem saber quem é ou o que faz...)

💡 O que é Informação?

  • É o dado contextualizado e processado.
  • Adquire um significado, reduz a incerteza e apoia decisões.
Exemplos:
• "A temperatura média em Redenção hoje é de 35°C."
• "A aluna matriculada no curso de TI se chama Maria."

📌 O que é um Fato?

  • Uma ocorrência ou registro de algo verificável e real.
  • O dado histórico imutável após ser armazenado em um sistema.
Exemplos:
• "A temperatura máxima em Redenção em 04/08/2026 registrou 35°C."
• "A estudante Maria tirou nota 10 no primeiro laboratório."

🏷️ O que são Metadados?

  • Dados sobre dados.
  • Descrevem a estrutura física e as regras dos dados salvos no sistema.
  • Funcionam como o "molde" ou "esqueleto" do banco.
Exemplos de Metadados de uma Tabela:
• O campo temperatura deve aceitar apenas número decimal.
• O campo nome_aluno deve ser texto com máximo de 100 caracteres.
• A data deve ser gravada no formato padrão AAAA-MM-DD.

Parte 2

Histórico e Evolução

Do papel aos modernos sistemas de arquivos e bancos relacionais.

📂 A Era dos Arquivos Planos (Flat Files)

No início, os dados de sistemas eram guardados em arquivos de texto simples (como .txt ou .csv) ou planilhas independentes para cada setor.

Dores Comuns:

❌ Redundância: Dados iguais repetidos em locais diferentes.

❌ Inconsistência: Dados diferentes para o mesmo conceito.

❌ Insegurança: Falta de controle refinado de quem acessa o quê.

🚀 O Modelo Relacional (1970)

  • Proposto pelo matemático Edgar F. Codd (IBM).
  • Propôs organizar informações em tabelas (linhas e colunas) ligadas entre si.
  • Criou as bases matemáticas para os bancos de dados modernos e para a linguagem SQL.
"O Modelo Relacional separou definitivamente a forma como o usuário vê as informações (lógica) da forma como são guardadas no disco (física)."

Parte 3

O que é Banco de Dados e SGBD?

A arquitetura de software para gerência de dados em larga escala.

🖥️ Definições Fundamentais

Banco de Dados

Coleção lógica e coerente de dados correlacionados com algum significado inerente, simulando as regras de um mini-mundo real (ex: Escola, E-commerce).

SGBD

Software intermediário que gerencia o acesso, a integridade física, a segurança contra falhas e as consultas ao Banco de Dados (ex: MySQL, Postgres, SQL Server).

Parte 4

Abstração de Dados

Entendendo a Arquitetura de Três Esquemas (ANSI/SPARC).

🏗️ A Arquitetura ANSI/SPARC

Os bancos de dados modernos se organizam em 3 camadas de abstração:

1. Nível Externo (Visão) — Como as visões de usuários finais e aplicativos são exibidas.
2. Nível Conceitual (Lógico) — Quais dados existem e como estão estruturados (tabelas e chaves).
3. Nível Interno (Físico) — Como os arquivos binários de dados estão alocados nos discos do servidor.

🔄 Independência de Dados

  • Física: Capacidade de mudar a estrutura física (ex: migrar do HD para o SSD, ou alterar indexadores de disco) sem precisar modificar as tabelas ou consultas SQL lógicas.
  • Lógica: Capacidade de alterar a estrutura de tabelas (ex: adicionar campos) sem quebrar as aplicações antigas (usando Views de segurança).
