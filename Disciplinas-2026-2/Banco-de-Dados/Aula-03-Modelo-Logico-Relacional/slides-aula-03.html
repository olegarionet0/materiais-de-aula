📌 3 Atributo Identificador → PK

O atributo sublinhado no DER vira a PRIMARY KEY


Uma Chave Primária deve ser:
✅ Única — dois registros não podem ter o mesmo valor
✅ Não nula — todo registro precisa ter uma PK
✅ Estável — o valor não muda ao longo do tempo

🤔 CPF é uma boa PK?

❌ CPF como PK

  • Pode ter erro de digitação
  • Menor de idade pode não ter
  • Requer validação extra
  • Se corrigir, afeta o banco todo

✅ ID Auto Incremento

  • Gerado automaticamente
  • Nunca se repete
  • Nunca é nulo
  • Nunca precisa mudar
id_aluno INT AUTO_INCREMENT PRIMARY KEY
